# Shad Up

― 英語学習を「楽しく・安く・シンプルに」 ―  

---

## 概要

Shad Up は、AI によって生成された英文を「1分で読める分量」で提供し、  
音読・リスニング（ブラウザ読み上げ）を通じて学習できます。

従来の語学学習における以下の課題：

- 面白くない教材
- 高額な学習サービス
- 複雑で使いにくいアプリ

これらに対し、本サービスは  
**「好きな内容を、短く、安く、シンプルに学べる環境」** を提供します。

---

## Features

- 1分程度で読める英文の自動生成（AI）
- 好きなテーマで英文作成
- 難易度 / テーマ / 長さのカスタマイズ
- 生成履歴の保存・再利用
- スマホ操作前提のシンプルUI
- ランダム再生・次へ再生機能
- 文章クリックによる部分再生

---

## 特徴（強み）

### ■ 学習の「楽しさ」を重視
従来の教材は内容が固定されており、興味のない文章を読む必要がありました。  
本サービスでは、**ユーザーの興味に基づいた文章をAIで生成**することで、継続しやすい学習環境を提供します。

---

### ■ 圧倒的な低コスト設計

- AI生成：低コスト（軽量モデル使用）
- 音声再生：ブラウザ標準機能を利用

→ 外部API依存を最小化し、**運用コストを極限まで削減**

---

### ■ シンプルなUX

機能を以下に限定：

- 生成
- 再生
- 保存

→ 学習に必要な最小限の操作のみで構成し、迷わない設計

---

## 工夫した点

### 1. ブラウザ音声の活用

- SpeechSynthesis API を使用
- 音声APIを使わずコスト削減
- 環境ごとに音声選択可能
- 文章単位クリック再生に対応

👉 従来の教材では難しい「ピンポイント再生」を実現

---

### 2. UI設計（スマホ最適化）

- タップ操作を前提に設計
- クリック可能領域を視覚的に明確化
- 操作ステップを最小化

---

### 3. 学習効率の最適化

- 1分で読める短文設計
- 保存機能による反復学習
- ランダム再生で飽きを防止

---

## 動作環境

- PC：Google Chrome
- Mobile：Android Chrome

---

## Tech Stack

- Frontend: HTML / CSS / JavaScript (Blade)
- Backend: Laravel (PHP)
- Database: MySQL
- Auth: Laravel Breeze
- AI: Gemini API
- Audio: Browser SpeechSynthesis API

---

## システム構成

- AI生成 → Controller → DB保存
- フロント側で再生制御（JavaScript）
- BladeによるUIレンダリング
